## 7. Flows

**Recover from admin lockout** (documentation corrected this session)
1. Shell into the host — every lever requires shell access.
2. `manage.py reset_superadmin_mfa` — removes the superadmin's TOTP device and revokes their sessions.
3. Log in with password alone, then re-enrol the authenticator immediately.
   - If the password is also lost, `manage.py reset_superadmin_password` first.
   - There is no third lever. `GUIDE.txt` previously listed `manage.py addstatictoken`, which does not exist: `otp_static` is deliberately not installed, since recovery codes are concept-locked out (`concepts/authenticate.txt`, `authenticate/docs/DATA_CONTRACT.md`). An operator following the old text during a real lockout would have hit `Unknown command`.
